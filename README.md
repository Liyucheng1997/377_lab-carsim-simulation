# VDLab · 网页版车辆动力学仿真

参照 CarSim / VI-CarRealTime 的建模思路实现的浏览器端整车动力学仿真平台，所有计算在本地浏览器完成，无需服务器和授权。

**当前版本：v1.0.0**

## 快速开始

```bash
npm install
npm run dev        # 开发模式，浏览器打开 http://localhost:5377
npm test           # 运行数值验证测试
npm run build      # 生成 dist/ 静态站点，可直接部署到任意静态服务器
```

## 功能

| 模块 | 内容 |
| --- | --- |
| 车辆模型 | 14 自由度（车身 6 + 车轮跳动 4 + 车轮转动 4）+ 轮胎松弛瞬态；0.5 ms 固定步长，比实时快 50–200 倍 |
| 轮胎 | 简化魔术公式：载荷敏感、联合滑移、外倾推力、回正力矩、松弛长度、低速模型 |
| 悬架 K&C | 轮心刚度、双斜率减振器、稳定杆、缓冲块、侧倾中心、抗点头/抗下蹲、外倾增益、轮跳转向、柔度转向 |
| 动力总成 | 发动机外特性、液力变矩器、闭锁离合器、自动换挡、开式/限滑差速器、FWD/RWD/AWD |
| 制动与主动安全 | 液压制动、ABS（含后轴低选与横摆力矩延迟）、ESC、TCS |
| 驾驶员 | 预瞄路径跟踪 + 横摆反馈、PI 车速控制、开环输入 |
| 试验工况 | 全油门加速、直线制动、对开路面制动、稳态回转、斜坡转向、角阶跃、正弦停滞 (FMVSS 126)、双移线 (ISO 3888-1)、蛇行、鱼钩、凸块、ISO 8608 随机路面、赛道圈速 |
| 结果 | Three.js 三维动画（多视角、轮胎力矢量、对比车）、可自定义曲线、按标准计算的评价指标、多次结果对比、CSV 导出 |
| 实时驾驶 | 键盘 / 手柄 / 方向盘驾驶员在环，可记录为仿真结果 |
| 车型库 | 4 款内置车型，可复制编辑，参数自动保存，JSON 导入导出 |
| 界面 | 苹果式简约设计（单一主题蓝、白底卡片、胶囊控件），支持深色模式，窄屏自适应 |

## 目录结构

```
src/core/      纯 TypeScript 物理核心（无 DOM 依赖，可在 Node 中运行）
  vehicle.ts     整车动力学模型
  tire.ts        魔术公式轮胎
  powertrain.ts  发动机 / 变矩器 / 变速器
  road.ts        路面高度与附着系数
  driver.ts      驾驶员模型
  procedures.ts  标准试验工况与评价指标
  simulator.ts   仿真运行与数据记录
  params.ts      参数定义、内置车型、线性特性估算
src/ui/        界面：工作区、参数编辑、实时驾驶、三维动画、曲线组件
tests/         数值验证测试（物理守恒、运动学、工况指标合理范围）
```

## 验证

`npm test` 运行 29 项数值验证：静止平衡与载荷守恒、低速阿克曼运动学、轮胎摩擦极限、4 款车型 × 13 个工况全部稳定运行，以及 0–100 km/h、制动距离、不足转向度、响应时间等指标落在工程合理范围。典型结果：0–100 km/h 4.0–8.0 s，100–0 km/h 制动距离 38–45 m，不足转向度 1.1–2.5 deg/g。

## 局限

车身姿态采用小角度假设；悬架为集总 K&C 参数而非多体连杆；转向系统无动力学（方向盘角直接输入）；内置车型为典型量级示例数据，工程使用请替换为实测数据。
